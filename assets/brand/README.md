# Assets da marca Juntô

Diretório reservado para os arquivos finais aprovados da marca.

Nomes previstos:

- `logo-primary.svg`: logotipo principal para sidebar e cabeçalhos;
- `logo-compact.svg`: versão reduzida;
- `favicon.svg`: favicon;
- `app-icon.svg`: referência para futuro ícone de aplicativo;
- `plus-jakarta-sans.woff2`: fonte local, caso seja fornecida.

Enquanto esses arquivos não forem entregues, o produto mantém o wordmark textual “Juntô” e carrega Plus Jakarta Sans pela folha oficial do Google Fonts, com fallback para fontes do sistema.
